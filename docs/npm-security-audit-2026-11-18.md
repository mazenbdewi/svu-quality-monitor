# npm security audit — 2026-11-18

This batch deliberately does not change JavaScript dependencies. The lockfile was audited with npm's registry on 2026-11-18:

- `npm audit --json`: 13 affected package entries (12 high, 1 critical).
- `npm audit --omit=dev --json`: 0 vulnerabilities.
- No `npm audit fix`, forced update, lockfile change, or package upgrade was performed.

The Docker build installs these tools only in the `frontend` stage. Node and the build dependency tree are not copied into the PHP or nginx runtime images. The exception is the generated browser bundle: Axios 1.18.1 is imported by `resources/js/bootstrap.js` and is shipped to browsers, although the application currently makes no Axios calls from its own source.
